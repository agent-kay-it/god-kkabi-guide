## Executive Summary (Discovery 1페이지)

| 축 | 핵심 발견 |
|----|-----------|
| **Problem** | 한국 방치형 RPG 유저는 정보가 디시·인벤·블로그·BlueStacks에 산재해 메타 변화·쿠폰·빌드 정보를 매번 따로 검색해야 함. 모바일 가독성·신뢰성·신선도가 모두 부족. |
| **Opportunity Top 3** | (1) 메타·티어 변화 추적 자동화 (2) 쿠폰 유효성 실시간 검증 (3) 빌드 시뮬레이터 + 비교 |
| **Top Assumption** | "검객 메타 추종 유저는 쿠폰 + 진령 조합 정보를 한 페이지에서 보면 디시·BlueStacks보다 우리 사이트를 우선 검색할 것이다" (Desirability) |
| **Riskiest** | 1인 운영 환경에서 콘텐츠 신선도(쿠폰·메타)를 디시 사용자보다 빠르게 유지할 수 있는가 (Feasibility) |
| **Killer Experiment** | 디시 마이너 갤러리에 "쿠폰 자동 만료 체크" 페이지 링크 시드 → 7일간 유입/이탈 측정 |

## STEP 1 — Brainstorm (가설 발산, 모든 통념 의심)

### 1.1 사용자 페인포인트 발산 (40개 이상 발산)

**정보 탐색 페인 (Information Friction)**
- P01. 쿠폰이 유효한지 매번 BlueStacks/LDPlayer 블로그를 돌며 확인해야 함
- P02. 디시 마이너 갤러리는 정보가 시간순으로 흘러내려가서 검색이 어렵다
- P03. 인벤은 갓깨비 전용 페이지가 없고 일반 게시판만 있다 (검색 결과 확인됨)
- P04. 나무위키는 업데이트가 느리고 r4 판 등 버전 혼선이 있다
- P05. BlueStacks 가이드는 SEO 점령했지만 광고 과다 + 신뢰도 의심
- P06. LDPlayer 가이드는 BlueStacks의 카피 수준이라 정보가 동일
- P07. 진령 티어 정보가 사이트마다 다르고 업데이트 시점이 불명
- P08. 빌드 추천을 글로만 적어놔서 "내 진령 3개로 어떤 시너지가 나는지" 비교 불가
- P09. 결투장 메타 변화 추적 불가 (디시에는 글이 산재)
- P10. 신규 진령 출시 시 채용률 데이터 0 — "써볼만한가?" 답을 못 얻음

**의사결정 페인 (Decision Friction)**
- P11. 무과금/소과금/중과금별 추천 빌드가 통일되지 않음
- P12. "999뽑기 어디에 써야 하나" 질문에 신뢰 가능한 가이드 없음
- P13. 직업 선택 (전사/검객/영매) 후 되돌리기 어려운데 사전 정보 부족
- P14. 코어·액티브·패시브 스킬 우선순위가 불명확
- P15. 제련(장비 강화) 확률·재료 효율 계산기 부재

**커뮤니티 페인 (Social/UGC Friction)**
- P16. 디시는 익명·트롤·욕설 노이즈가 심해 진지한 빌드 토론 어려움
- P17. 네이버 카페는 가입 절차가 번거롭고 모바일 가독성 나쁨
- P18. 자기 빌드를 공유할 표준 포맷이 없음 (스샷 + 자유서술뿐)
- P19. 좋아요/추천 기반의 빌드 큐레이션 부재
- P20. 신규 유저가 고인물에게 질문하기 위한 진입장벽 높음

**모바일/UX 페인**
- P21. 인벤·디시 모두 모바일에서 광고 가림·터치 영역 작음
- P22. 데이터 로드가 느림 (이미지 최적화 X)
- P23. 다크모드 미지원 또는 강제 라이트모드
- P24. 검색 기능이 사이트 내에서 약함

**운영자/B2B 페인 (V3 시드)**
- P25. 게임사는 자체 데이터(KPI)만 보지 유저 커뮤니티의 메타 인식·이탈 신호를 못 봄
- P26. 게임사는 진령 채용률을 알지만, "왜 안 쓰는지" 정성 데이터 없음
- P27. 쿠폰 발급 후 실제 유효 클릭률·만료 후 이탈률 추적 어려움
- P28. 결투장 봇/매크로 탐지 시그널을 커뮤니티 토론에서만 얻을 수 있음
- P29. 콜라보 (카카오프렌즈 등) ROI를 외부 데이터로 검증 어려움
- P30. 출시 직후 4-12주차 이탈 가속 구간의 외부 시그널 부재

**롱테일 페인**
- P31. 비경 던전 클리어 시간 비교 데이터 없음
- P32. 보스 패턴 영상이 유튜브에 흩어져 있음
- P33. 영매 직업 정보가 검객보다 압도적으로 부족
- P34. 길드(향후 추가될 가능성) 콘텐츠 정보 사전 부재
- P35. 시즌패스 가성비 분석 부재
- P36. 진령 동행/비동행 효과 차이를 표로 비교한 자료 부족
- P37. 이벤트(시즌) 종료일·보상 캘린더 부재
- P38. 신마킬·고난도 컨텐츠 공략 영상-텍스트 매핑 부재
- P39. 신규 유저를 위한 35→45렙 만렙 빌드 트랜지션 가이드 부재
- P40. 한국어 게임이지만 검색어 SEO에서 일반 명사("키우기 공략")와 경쟁이 어려움

> **통념 의심 (Inversion)**
> - "방치형은 정보가 단순할 것" → 실제론 진령 11종 × 직업 3종 × 스킬 3계열 × 제련 = 조합 폭발
> - "디시가 있으니 가이드 사이트는 필요 없을 것" → 디시는 흘러가지만 가이드는 누적된다 (SEO 무기)
> - "공식 가이드가 나오면 끝일 것" → 공식은 자기 메타 비판 못함, 비공식의 자유도가 결정적

### Top 5 검증 우선순위

1. **D5** (Feasibility, I=5 R=5) — "MVP의 데이터 스키마가 V3에서 그대로 쓰일 수 있는가?" → **MVP 설계 시점부터 검증해야 함** (실패 시 V3 자체가 무산)
2. **D1+D2** (Desirability/Viability, I=5 R=5) — "게임사가 우리 데이터를 살까?" → 임팩트는 최대지만 검증은 V2 후반
3. **A1** (Desirability, I=5 R=4) — "유저가 우리를 우선 검색하는가?"
4. **A3** (Feasibility, I=5 R=4) — "1인 운영자가 신선도를 BlueStacks보다 빠르게 유지 가능한가?"
5. **A2** (Desirability, I=5 R=3) — "쿠폰 자동 체크가 신뢰받는가?"

## STEP 4 — Experiments (각 Top 5 가정의 검증 실험)

### EXP-1 (검증: D5) — 데이터 스키마 사전 설계 + 더미 시뮬레이션
- **목표**: MVP 데이터 스키마가 V3 B2B 패키지 (진령 채용률 리포트, 이탈 시그널, 결투장 트렌드) 까지 마이그레이션 없이 수용 가능한가
- **방법**: 산출물 04-prd.md §B2B 자산화 로드맵에 V3 가상 리포트 3종 예시를 먼저 작성 → 역으로 MVP 데이터 스키마 도출 (이벤트 모델: `build_logged`, `coupon_clicked`, `tier_view`, `pvp_build_view`)
- **성공 기준**: 가상 V3 리포트 3종을 MVP 스키마만으로 SQL-equivalent 쿼리 가능
- **기간/비용**: 1일 / 0원 (운영자 설계만)
- **실패 시 결정**: 스키마 재설계 → MVP 일정 지연 감수

### EXP-2 (검증: A1) — Beachhead 키워드 시드 침투 테스트
- **목표**: 검객 메타 추종 유저가 우리 사이트를 우선 클릭하는가
- **방법**: MVP 배포 후 디시 마이너 갤러리(up999) + 네이버 카페 5곳에 "검객 메타 빌드 + 쿠폰 자동 체크" 단일 페이지 링크 시드 (운영자 직접 작성, 광고 아님) — 7일간
- **성공 기준**: GA4 referer 클릭 100+ / 평균 체류시간 60초+ / 이탈률 70% 미만
- **기간/비용**: 14일 / 0원
- **실패 시 결정**: 타겟팅 수정 (영매·전사로 베이커헤드 재정의)

### EXP-3 (검증: A3) — 운영자 신선도 SLA 자가 검증
- **목표**: 1인 운영자가 주 2-3회 업데이트로 BlueStacks(주 1회 미만 추정) 보다 빠른가
- **방법**: 14일간 BlueStacks·LDPlayer 가이드 변경 일자 추적 vs 본 사이트 변경 일자 비교 (스크립트로 BlueStacks 페이지 변경일 모니터)
- **성공 기준**: 동일 메타 변경 (예: 진령 패치) 발생 시 본 사이트가 평균 24시간 이내 반영, BlueStacks는 72시간+
- **기간/비용**: 14일 / 0원
- **실패 시 결정**: 자동화 도입 (LLM 요약 + 디시 RSS 수집)

### EXP-4 (검증: A2) — 쿠폰 자동 체크 페이지 베타
- **목표**: 쿠폰 만료 자동 표시가 디시·BlueStacks보다 신뢰받는가
- **방법**: MVP 단일 페이지("/coupon") 배포 → 디시에 공유 + 7일간 클릭/공유 추적
- **성공 기준**: 페이지 PV 500+ / 외부 공유(SNS 백링크) 5+
- **기간/비용**: 7일 / 0원
- **실패 시 결정**: 형식 재설계 (캘린더 뷰 등)

### EXP-5 (검증: D1+D2) — 게임사 가상 영업 패키지 작성
- **목표**: 가상의 B2B 리포트 1부를 작성하면 게임사가 ₩50M+ 가치를 인정할 만한가
- **방법**: V3 단계 진입 전 단계(V2 후반)에 가상의 "갓깨비 메타 인사이트 분기 리포트 Q1" 1부 작성 → 모바일 게임 PM/사업개발 지인 3명에게 가격 의향 조사 (qualitative)
- **성공 기준**: 3명 중 2명 이상이 "₩30M-100M 사이의 ARR 가치 있음" 답변
- **기간/비용**: V2 후반 / 0원
- **실패 시 결정**: 비즈니스 모델 피봇 (광고 의존)

## 추가 발견 (실측 기반, 2026-05-14 보강)

### F-01. 갓깨비 키우기는 4399(Joy Games) 한국 지사가 퍼블리싱한 후속작

- Joy Nice Games = 4399 (중국 인터넷 엔터테인먼트 플랫폼)의 한국 브랜드 = Juxin Network Limited [확인됨]
- 갓깨비 키우기는 버섯커 키우기(2023-12 출시, 한국 매출 6,400만 달러/2개월)의 후속작
- 갓깨비는 2025-04-18 정식 출시, 카카오프렌즈 콜라보(라이언/어피치/춘식) 포함
- 출시 약 1개월 시점 추정치: 약 70K 다운로드 / $3M 매출 (출처 검색 결과 — 검증 필요)

> **비즈니스 함의**: V3 B2B 자산화의 잠재 인수자는 단일 게임사(Joy Games)가 아닌 **4399 그룹 한국 사업부 전체**. 동일 모회사의 후속작(갓깨비 2, 또 다른 키우기 시리즈)에 데이터·UX 자산을 재활용 가능하다는 점이 핵심 영업 포인트.

### F-02. 갓깨비 키우기는 다국어 출시 게임 (글로벌 확장 시드)

- 사전 등록 게시판에 표시된 언어: 한국어/중국어 번체/베트남어/태국어/러시아어/포르투갈어/스페인어/프랑스어/독일어/일본어/인도네시아어/아랍어 (12개+)
- **함의**: MVP는 한국어 우선이지만 V2/V3에서 i18n 구조로 확장 가능. 영어 가이드 시장은 BlueStacks가 영문판도 점령 중 → 일본/대만 시장이 next target.

### F-03. 인벤은 갓깨비 전용 페이지가 없다 (베이커헤드 빈자리)

- 인벤은 게이머 토론장 일반 게시판에 갓깨비 글 산재만 존재. 전용 가이드 페이지 부재.
- 인벤 자체 일평균 UV 140만, PV 1억-1.2억 — 게임 가이드 시장 표준 벤치마크.
- **함의**: 갓깨비 인벤 전용 페이지가 만들어지면 우리의 가장 큰 경쟁자가 됨. 인벤이 갓깨비 페이지를 만들기 전 6-12개월이 "선점 윈도우".

### F-04. Game8 일본 사례는 V3 인수 시나리오의 가장 유사한 벤치마크

- Game8: 2014년 설립 → 2015년 Gunosy에 인수 (조건 비공개)
- 2021년 월 PV 6,200만, 11M unique users
- **함의**: 1인 운영 가이드 사이트도 트래픽 임계점(월 PV 1,000만+)에 도달하면 게임 미디어 사가 인수한 선례 존재. 우리 목표는 더 작은 임계점에서 4399그룹 직접 라이선싱.

### F-05. 한국 비공식 팬사이트 법적 가이드라인

| 항목 | 합법성 | 근거 |
|------|-------|------|
| 게임 규칙·시스템 설명 | ✅ 합법 | 저작권법은 아이디어 보호 X, 표현만 보호 |
| 공식 스크린샷 핫링크 (Google Play CDN) | ⚠️ 회색지대 | 핫링크 자체는 합법, 단 상표적 사용 시 부정경쟁방지법 위반 가능 |
| 게임명 사용 ("갓깨비 키우기 가이드") | ✅ 합법 (조건부) | "비공식 팬 가이드" 디스클레이머 필수 |
| 게임 BGM·아트워크 복제 | ❌ 위법 | 저작권 침해 |
| 유저 빌드·메타 분석 데이터 수집 | ✅ 합법 | 사용자 동의(PIPA) 절차 준수 시 |

> **가드레일**: 홈/푸터에 "본 사이트는 Joy Nice Games / Juxin Network와 무관한 비공식 팬 가이드입니다" 명시. 광고/유료화 시 "게임사 공식 후원 X" 추가 명시.
