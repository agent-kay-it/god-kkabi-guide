## 운영자가 즉시 의사결정해야 할 Top 3 질문

### Q1. 🔴 도메인 선정 (MVP 배포 직전)
- 추천: **게임-agnostic 도메인** (예: `metaguide.kr`, `idleinsight.kr`) — V3에서 4399 그룹 후속작(갓깨비 2 등)으로 재활용 가능
- 대안: `gokkaebi-guide.com` (게임명 직접, 강한 SEO, but 게임 인기 종료 시 재활용 불가)

### Q2. 🔴 V0 콘텐츠 시드 작성 방식 (MVP 콘텐츠 시작 시)
- 추천: **하이브리드 (운영자 70% + 디시 가공 인용 30%)** — 1인 부담 분산 + 법적 회색지대 최소화

### Q3. 🟡 데이터 스키마 사전 검증 — V3 가상 리포트 3종 (Sprint 0)
- 추천: **MVP 시작 전 가상 V3 리포트 3종 작성** (1-2일 추가) → 스키마가 V3까지 추가 마이그레이션 없이 수용 가능한지 역검증
- 근거: Discovery §Step 3 R.A.T. — D5 가설이 무산되면 V3 자체가 무산. 가장 위험한 가정이므로 가장 먼저 검증.

## MVP 정의 (한 페이지)

### ✅ In Scope (M1-M3)
- 콘텐츠 9섹션 (원본 HTML 이식)
- 모바일 first 반응형 + 다크/골드 한국 오컬트 무드 + Lighthouse ≥90
- 쿠폰 자동 체커 (운영자 입력 + 클릭 복사 + 만료 D-day)
- 직업 진단 (3-5문항)
- 진령 11종 카드 + 검객 메타 빌드 페이지
- GA4 + Firestore 데이터 스키마 사전 설계 (V3 호환)
- SEO 롱테일 50개 키워드 + 법적 디스클레이머

### ❌ Out of Scope (V1+)
- 로그인 / 댓글 / UGC / 빌드 공유 / 좋아요 (모두 V1)
- 광고 (V1) / 결제 (V2) / 빌드 시뮬레이터 (V2) / 채용률 차트 (V2)
- 다국어 (V2 후반) / 모바일 앱 (PWA로 대체)
- B2B 패키지 / API (V3)

### 30/90일 성공 기준
| 시점 | DAU | Lighthouse | SERP "갓깨비 키우기 공략" | 쿠폰 페이지 누적 PV |
|------|-----|-----------|--------------------------|------------------|
| 30일 | 30+ | ≥90 | 인덱싱 완료 | 100+ |
| 90일 | 100+ | ≥90 | 상위 30위 | 500+ |

### 폐기/피봇 트리거 (4.5/6개월차)
- M4.5: DAU 100 미만 → 톤 피벗 또는 콘텐츠 깊이 강화
- M6: DAU 200 미만 → MVP 폐기 검토, 후속 4399 게임 도메인 재활용
