## §2. 운영자 게이트 단계 (V2 후속 또는 V3 진입 시)

### Step 1: 페이지 마이그레이션 (`app/*` → `app/[locale]/*`)

기존 23 routes 모두 `[locale]` dynamic segment 안으로 이동:
- `app/page.tsx` → `app/[locale]/page.tsx`
- `app/class/page.tsx` → `app/[locale]/class/page.tsx`
- ... (모든 페이지)

API routes (`app/api/*`)는 locale 분리 불필요 — 이동 X.

### Step 2: middleware.ts 통합

```ts
import { auth as nextAuthMiddleware } from '@/lib/auth/config';
import createIntlMiddleware from 'next-intl/middleware';
import { locales, defaultLocale } from './i18n/config';

const intlMiddleware = createIntlMiddleware({
  locales,
  defaultLocale,
  localePrefix: 'as-needed', // ko는 prefix 생략
});

export default async function middleware(req: NextRequest) {
  // 1) NextAuth authorized 체크
  const session = await nextAuthMiddleware(req);
  // 2) intl 처리
  return intlMiddleware(req);
}
```

### Step 3: 번역 작성

### Step 4: SEO 갱신

- hreflang alternate links (next-intl 자동 처리)
