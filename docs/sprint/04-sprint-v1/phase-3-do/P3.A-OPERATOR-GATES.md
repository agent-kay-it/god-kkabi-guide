## 작업 흐름 (10-15분)

### 1. fonttools 설치 (Python 환경)

```bash
# Python 3.8+ 필요
pip install 'fonttools[woff]' brotli zopfli
```

검증:
```bash
pyftsubset --help | head -3
```

### 2. 백업 + Subset 빌드

```bash
cd /Users/popup-kay/Documents/GitHub/agentkay/god-kkabi-guide

# 백업 (원본 보존)
cp public/fonts/PretendardVariable.woff2 public/fonts/PretendardVariable-full.woff2.bak

# Subset 빌드 (KS X 1001 한글 2350자 + Latin Basic + Latin-1 Supplement + 자모 + 구두점)
pyftsubset public/fonts/PretendardVariable-full.woff2.bak \
  --output-file=public/fonts/PretendardVariable.woff2 \
  --flavor=woff2 \
  --unicodes=U+0020-007E,U+00A0-00FF,U+3131-318E,U+1100-11FF,U+AC00-D7A3,U+2010-203E,U+FF00-FFEF \
  --layout-features='*' \
  --no-hinting \
  --desubroutinize \
  --recommended-glyphs
```

### 3. 검증

```bash
# 크기 확인 (목표: ≤ 500KB)
ls -la public/fonts/PretendardVariable.woff2

# 또는 검증 스크립트
bash scripts/verify-font-subset.sh
```

### 4. 빌드 + 시각 검증

```bash
tene run -- pnpm build
tene run -- pnpm start
# 브라우저에서 http://localhost:3000 → DevTools Network → font 다운로드 크기 + 한글 표시 정상 확인
```

### 5. Lighthouse Mobile 재측정

```bash
npx lighthouse http://localhost:3000/ --form-factor=mobile --throttling-method=simulate --quiet \
  --output=json --output-path=./lh-v1.json
node -e "console.log('Performance:', JSON.parse(require('fs').readFileSync('lh-v1.json')).categories.performance.score)"
```

**목표**: Performance ≥ 0.85 (lab metric).

## 문제 해결

### Q. pyftsubset 명령어 없음
`pip install fonttools[woff]` 재실행 + `which pyftsubset` 확인.

### Q. brotli compression 오류
`pip install brotli` 별도 설치.

### Q. subset 후 크기 700KB+
- `--unicodes` 범위에서 `U+1100-11FF` (Hangul Jamo 256자) 제외 가능 (KS X 1001 완성형으로 충분한 경우)
- `--no-glyph-names` 추가 (glyph 이름 제거 — 추가 5% 감소)

### Q. 한글 표시 깨짐
- `--layout-features='*'` 누락 → GSUB/GPOS 테이블 손실 → variable weight 깨짐
- `--recommended-glyphs` 누락 → .notdef glyph 누락 → 일부 글리프 표시 X
