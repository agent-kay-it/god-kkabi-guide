# P3.D 운영자 게이트 — Google AdSense

## 작업 흐름 (대기 ~14일)

### 1. AdSense 가입

https://www.google.com/adsense/start/

1. Google 계정 (kay@agentkay.it) 로그인
2. 사이트 도메인 등록 (예: `god-kkabi-guide.vercel.app` 또는 커스텀 도메인 G4)
3. 결제 정보 입력 (계좌)
4. 정책 동의

### 2. ads.txt 게시

`public/ads.txt` 파일에서 `pub-0000000000000000`을 발급된 publisher ID로 교체:

```diff
- google.com, pub-0000000000000000, DIRECT, f08c47fec0942fa0
+ google.com, pub-XXXXXXXXXXXXXXXX, DIRECT, f08c47fec0942fa0
```

git commit + Vercel deploy 후 `https://{domain}/ads.txt` 접근 가능 확인.

### 3. 사이트 검토 (~7-14일)

AdSense 콘솔에서 "사이트 → 추가" → 도메인 입력 → 검토 신청.
승인 시 이메일 통지 + 콘솔에서 "사이트 ✓" 표시.

### 4. 광고 단위 발급 (승인 후)

콘솔 → "광고 → 광고 단위 추가":

**Sticky 하단** (반응형):
- 이름: `god-kkabi-sticky-bottom`
- 광고 단위 ID: `slot=XXXXXXXXXX` 받음

**인피드** (네이티브):
- 이름: `god-kkabi-infeed-post-list`
- 광고 단위 ID: `slot=XXXXXXXXXX` 받음

### 5. Vercel env 추가

Vercel Project Settings → Environment Variables:

```
NEXT_PUBLIC_ADSENSE_PUBLISHER=pub-XXXXXXXXXXXXXXXX
NEXT_PUBLIC_ADSENSE_SLOT_STICKY=XXXXXXXXXX
NEXT_PUBLIC_ADSENSE_SLOT_INFEED=XXXXXXXXXX
```

Production / Preview / Development 모두 적용 (단, dev 환경은 컴포넌트에서 미렌더).

### 6. 검증

1. production deploy 후 `https://{domain}/post` 접근
2. PIPA 5번째 `advertising` 동의한 비-admin 사용자로 로그인
3. 하단 sticky 광고 + 인피드 슬롯 노출 확인
4. admin (kay@agentkay.it) 사용자로 로그인 → 광고 미노출 확인 (본인 클릭 차단)
5. AdSense 콘솔 → Reports에서 impression 발생 확인 (~1시간 후)

## 정책 가드 (코드 측면 — 이미 구현 완료)

`app/layout.tsx`의 `showAds` 가드:
```ts
const showAds =
  isProduction &&             // 1. NODE_ENV=production
  Boolean(adsensePublisher) &&  // 2. env 설정
  !isAdminUser &&             // 3. admin role 미노출 (본인 클릭 차단)
  advertisingConsent;         // 4. 사용자 advertising 동의 (PIPA 5번째)
```

→ 정책 위반 사전 차단 완료.

## non-personalized ads fallback (선택)

EU 사용자 GDPR 대응 필요 시 (한국 메인이라 V1.5에서 검토):

```html
<script>
  window.adsbygoogle = window.adsbygoogle || [];
  window.adsbygoogle.requestNonPersonalizedAds = 1;
</script>
```

`AdSenseScript` 컴포넌트에 옵션으로 추가 가능.
