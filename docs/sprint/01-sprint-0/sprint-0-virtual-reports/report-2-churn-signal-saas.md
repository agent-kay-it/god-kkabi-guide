> **리포트 형태**: 월 구독 SaaS — 주간 이탈 알람 (Slack/이메일) + 실시간 대시보드

> **대상 고객**: Joy Net Games (한국 사업부) 운영팀 / JOY MOBILE NETWORK PTE. LTD. 사업개발 임원 / 4399 한국 지원조직

> **본 가상 리포트 가정**: 12주 / 빌드 1,000건 / 댓글 5,000건 / DAU 2,000 / 페이지 funnel 240,000건

## 1. Executive Summary

### 1.1 한 줄 결론

**"갓깨비 키우기 이탈 시그널은 (1) '999뽑기 분배 불명확' 페인포인트가 신규 유저 1주차 이탈의 28.1%를 차지, (2) 쿠폰 만료 후 7일 내 가이드 사이트 재방문율 -41%, (3) 결제 단계 2단계(시즌패스 선택)에서 이탈 64.3% 발생 — 이 3개 시그널을 운영팀이 7일 이내 대응 시 월 매출 추정 ₩50M-180M 보전 가능합니다."**

### 1.2 4-Perspective Value

| 관점 | 값 |
|------|------|
| **Problem (왜 필요한가)** | 4399/Joy Games는 인게임 텔레메트리(접속 끊김, 결제 실패)는 알지만 "왜 이탈했는가"의 정성적 맥락이 부족. 페이지 funnel + 댓글 NLP + 빌드 폐기 시그널로 이탈 직전 행동을 사전 포착. |
| **Solution (어떻게 해결하는가)** | (1) 페이지별 이탈률 funnel 시각화 (2) 페인포인트 NLP TOP10 부정 토픽 주간 변동 추이 (3) 결제 이탈 단계 식별 (4) 빌드 다양성 지수로 메타 피로도 측정. |
| **Function UX Effect (게임사가 체감하는 것)** | (1) 주간 이탈 위험 알람 자동 발송 (Slack #ops 채널). (2) 페이지 funnel 대시보드로 운영팀 1일 1회 모니터링. (3) 이탈 방지 패치 우선순위 자동 추천. |
| **Core Value (한 문장 가치)** | "공식 텔레메트리가 못 잡는 '이탈 직전 7일 행동'을 매주 자동 시각화하여, 운영팀의 패치 우선순위 결정을 1주일 앞당긴다." |

### 1.3 Top 3 발견

1. **신규 유저 1주차 페인 1위: '999뽑기 분배 불명확'** — 페인포인트 NLP에서 28.1% 점유. 게임 내 튜토리얼 보강 시급.
2. **쿠폰 만료 후 7일 이탈**: 가이드 사이트 쿠폰 페이지 PV는 만료 후 -41%, 게임 내 결제 PV도 약 -28% 추정. 쿠폰 만료 사이클 = 이탈 사이클.
3. **결제 단계 2단계 이탈 64.3%**: '시즌패스 선택 화면'에서 이탈 가장 큼. UI 또는 가격 인지 문제.

## 2. 메서드론

### 2.1 데이터 수집

- **수집 기간**: 12주 (2026 Q2) [가상]
- **샘플 크기**:
  - 페이지 funnel 이벤트: 240,000건 (DAU 2,000 × 12주 × 일평균 14.3 PV)
  - 댓글: 5,000건 (NLP 분석 대상)
  - 빌드 폐기 시그널: 빌드 작성 후 30일 내 미수정 + 미본인좋아요 (Soft churn signal)
  - 결제 이탈 funnel: V2 결제 통합 후 데이터 (Sprint 0 시점 가설)
- **데이터 익명화**: user-agent hash + uid 해시. PIPA 동의 유저만 NLP 대상.

### 2.2 가공 방법

- **페이지 funnel**: `events.page` 시퀀스를 session_id로 grouping → Markov chain 전이 확률 계산 → 이탈 노드 식별
- **NLP 클러스터링**: 댓글 텍스트를 KoBERT 임베딩 → DBSCAN 클러스터링 → 부정 sentiment 토픽 추출 → 주간 빈도 추이
- **빌드 폐기 시그널**: `builds.updated_at`이 30일 이상 동결 + `likes_count = 0` + 같은 uid의 새 빌드 작성 부재 → 게임 이탈 추정
- **결제 이탈**: `events.event_name = 'payment_drop'` 단계별 (V2 결제 도입 후)

### 2.3 한계 (가설 — 검증 필요)

- ⚠️ **가이드 사이트 ≠ 게임 이탈**: 가이드 사이트 이탈은 게임 이탈을 부분 반영. 게임 내 텔레메트리와 상관성 검증 필요.
- ⚠️ **NLP 정확도**: 한국어 게임 슬랭 ("팟나감", "탈주") 토큰화 어려움. 도메인 fine-tuning 필요.
- ⚠️ **세션 정의**: 30분 idle = 세션 종료 가정. 모바일 백그라운드 사용 시 부정확.
- ⚠️ **결제 데이터 부재**: V2 시점까지 가이드 사이트 결제 미보유 → R2-C4는 V2 후반에 첫 측정.

## 3. 핵심 분석 — 5개 차트

### 3.1 R2-C1: 페이지 funnel 이탈률

```
페이지 순서 (신규 유저 첫 3분 평균 경로)         이탈률
1. 메인 (/)                                      0% (entry)
2. 직업 (/class)                                 8.2%
3. 진령 (/jinryeong)                             18.7%
4. 쿠폰 (/coupon)                                 7.1%
5. 검객 메타 빌드 (/builds/meta-swordsman)      42.5%  ← 최대 이탈
6. 직업 진단 (/class-quiz)                       11.3%
7. 출처 (/sources)                               68.1%  ← 최종 이탈
```

**발견**:
- **5단계 검객 메타 빌드에서 42.5% 이탈** — 콘텐츠 깊이가 부족하거나 모바일 가독성 문제
- 7단계 출처 페이지 이탈은 자연스러움 (사이트 탈출)
- 직업 진단(/class-quiz)은 이탈률 11.3%로 양호 → 인터랙티브 콘텐츠 효과

**액션**: 검객 메타 빌드 페이지 리뉴얼 우선순위 1. 빌드 시뮬레이터(V2) 추가 시 이탈률 -15%p 목표.

1     999뽑기 분배 가이드 부재            487            -0.78    +12%
2     쿠폰 만료일 정보 부정확             392            -0.71    +8%
3     결투장 빌드 추천 부정확             318            -0.65    -3%
4     진령 강화 재료 부족                 287            -0.68    +5%
5     결제 패키지 가성비                  263            -0.74    +2%
6     자동 사냥 효율 떨어짐               241            -0.59    +9%

**발견**:
- TOP1 '999뽑기 분배' = 신규 유저 1주차 페인. 게임 내 튜토리얼 보강 시 1주차 retention +8%p 가능 [가설]
- TOP5 '결제 패키지 가성비'는 가이드 사이트 측면이지만 게임 결제 행동에 직결. 가성비 인지 부족이 결제 이탈 1차 원인.
- 주간 변동 +12% (TOP1) → 신규 유저 유입 증가 + 가이드 사이트 도달 전 페인 누적.

### 3.3 R2-C3: 보스 던전 별점 분포 (V1+ ratings 컬렉션 필요)

```
보스 던전     평균 별점 (1-5)   투표 수    감정 일관성
일일 보스 1     4.2            387        높음
일일 보스 2     3.8            312        중간 ("난이도 격차" 댓글 24%)
주간 보스 1     3.4            198        낮음 ("진령 의존도 큼" 24%)
주간 보스 2     2.9            142        매우 낮음 ("재미 없음" 31%)
도깨비 협동 보스 4.1            89         높음
```

**발견**: 주간 보스 2의 평균 별점 2.9 → 보스 콘텐츠 재설계 또는 보상 강화 필요. 동시에 댓글 31%가 "재미 없음" 사유 → 가챠 시뮬레이터로 재미 보강 가능.

⚠️ **MVP 스키마 매핑 이슈**: 별점 컬렉션이 MVP 스키마에 없음. V1+에서 `boss_ratings` 컬렉션 또는 `builds` 컬렉션의 `tags`에 '난이도-격차' 등 메타 태그 추가 필요.

### 3.4 R2-C4: 결제 이탈 단계 funnel (V2+ 결제 도입 후)

```
결제 단계 (가이드 사이트 프리미엄 구독 ₩4,900/월)   이탈률
1. 메인 → 가격 페이지 진입                          0%
2. 가격 페이지 → 결제 화면 (시즌패스 선택)          64.3%  ← 최대 이탈
3. 결제 화면 → 결제 정보 입력                       28.1%
4. 결제 정보 입력 → 최종 결제 완료                  14.7%
최종 전환율 (메인 진입 → 결제 완료): 약 2.2%
```

**발견**: 단계 2(시즌패스 선택)에서 가장 많이 이탈. 가설:
- (가) 가격이 비싸 보임 → ₩2,900/월 옵션 추가 검토
- (나) 시즌패스 혜택이 불명확 → 비교표 UI 추가
- (다) 결제 의향 시점에 환불 정책 보이지 않음 → 환불 신뢰성 보강

⚠️ **V2 결제 도입 전까지 본 차트는 가설**. V2 종료 후 실측 가능.

W2    2.28

## 4. 인사이트 도출

### 4.1 패턴 식별

1. **신규 유저 1주차 페인 = '정보 산재'**: 999뽑기 분배 / 쿠폰 유효성 / 진령 강화 등 모두 정보 접근성 문제. 게임 내 튜토리얼 강화 또는 가이드 사이트 신규 유저 온보딩 흐름 개선 필요.
2. **이탈 사이클이 쿠폰 만료 사이클과 일치**: 쿠폰 만료 후 7일 이내 가이드 사이트 재방문 -41% → 쿠폰 보상이 retention 핵심 트리거임을 시사. 정기적 쿠폰 발행 정책 검토.
3. **결제 의사 vs 실제 결제 사이의 정보 갭**: 가격 페이지 도달 유저의 64.3%가 결제 화면 단계에서 이탈 → 가격은 충분히 인지하나 결제 결심 직전 정보 부족.
4. **빌드 다양성 하락**: 12주간 Shannon -23% → 메타 콘텐츠 피로감 진입 시그널. 다음 분기 신규 진령 또는 시너지 패치 필요.

### 4.2 시장/유저 행동 해석

- **방치형 RPG 유저의 정보 의존**: 자동 전투가 핵심이지만 빌드/진령 선택에 정보 비용 큼. 가이드 사이트는 게임의 외부 UI 확장 역할.
- **결제 이전 단계의 정보 부족이 결제 이탈의 주된 원인**: 가성비/비교/환불 정책이 결제 직전에 보이지 않으면 단계 2 이탈 발생.
- **콘텐츠 피로감은 단계적**: 빌드 다양성 하락 → 가이드 사이트 재방문 감소 → 게임 내 이탈로 전이. 가이드 사이트 데이터로 게임 이탈 사전 예측 가능.

## 5. 권고사항 (4399/Joy Games 적용 가능 액션 10건)

1. **신규 유저 999뽑기 튜토리얼 보강**: 게임 내 튜토리얼에 '확률업 이벤트 시점 활용' 가이드 5초 영상 추가.
2. **쿠폰 발행 주기 정기화**: 매월 1일 + 보름 + 시즌 시작 정기 발행 → 만료 사이클 = retention 사이클.
3. **결제 화면 단계 2 UI 리뉴얼**: 시즌패스 선택 화면에 (가) 가성비 비교표 (나) 환불 정책 명시 (다) 신뢰 배지 추가.
4. **빌드 다양성 KPI**: Shannon Entropy ≥1.8 유지. 미달 시 다음 분기 신규 진령 출시 트리거.
5. **검객 메타 빌드 페이지 리뉴얼**: 이탈률 42.5% → V2 시뮬레이터 우선 도입 + 빌드 비교 인터랙션 추가 (가이드 사이트 측).
6. **이탈 알람 자동화**: 주간 이탈률 +5%p 시 운영팀 Slack 자동 알람 (이 SaaS의 핵심 기능).
7. **NLP 토픽 모니터링**: 페인포인트 TOP10에 신규 토픽 진입 시 운영팀 알람.
8. **자동 사냥 효율 패치**: TOP6 페인 '자동 사냥 효율 떨어짐' +9% 주간 변동 → 검토 우선순위 격상.
9. **보스 던전 2 리밸런싱**: 별점 2.9 / "재미 없음" 31% → 보상 +20% 또는 메커니즘 변경.
10. **신규 유저 1주차 멘토 시스템**: 가이드 사이트의 신규 가입자에게 시드 멘토(베테랑 유저) 매칭 → 페인 1주차 해소.
