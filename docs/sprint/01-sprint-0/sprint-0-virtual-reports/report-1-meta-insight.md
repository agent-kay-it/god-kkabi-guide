## 1. Executive Summary

**"2026 Q2 갓깨비 키우기 한국 메타는 '검객+서해용왕+홍길동' 정석 빌드가 점유율 38.4%(전기 대비 +5.7%p)로 굳어지는 한편, 영매 빌드는 '구미요호+항아' 안정 조합이 회복 추세(+3.1%p)이며, 신규 진령 출시 후 48시간 내 채용률은 평균 12.4%로 전작(버섯커 키우기) 대비 4.1%p 낮아 콘텐츠 신선도 보강이 시급합니다."**

1. **검객 메타 고착화**: 검객 빌드 50.2% (전기 +1.4%p) — 0.4%p 차로 50% 임계 돌파. 직업 균형 패치 시그널.

## 4. 인사이트 도출

### 4.1 패턴 식별

1. **0티어 진령 과점**: 홍길동·서해용왕이 모든 직업에서 60%+ 채용 → 게임 밸런싱 의도 외 보편성 발생. 다른 SSR 진령의 매력도 보강 필요.
2. **결투장 단조화**: TOP1 빌드 38.4%, TOP5 누적 74.3% → PvP 의사결정의 단순화. 결투장 보상이 메타 다양성을 보상하도록 조정 필요.
3. **신규 진령 채용 둔화**: 출시 후 48h 채용률이 전작 대비 -4.1%p → 신규 진령 출시 동기 약화. 가챠 패키지 가격 또는 진령 스킬 효과 재검토.
4. **영매 회복세**: 구미요호 +8%p / 항아 +6%p → 영매 직업이 신규 빌드 시도 활발 (검객 메타 다양성 결핍과 대조).

### 4.2 시장/유저 행동 해석

- **검객 유저는 메타 정석 빌드에 안주**: 검객 메타 빌드(홍·서해·음) 채용률 38.4%. 새 진령 출시에도 빌드 변경 동기 약함. → 신규 진령 출시 시 검객 특화 시너지 강화 필요.
- **영매 유저는 빌드 다양성 추구**: 영매 직업 내 진령 조합 다양성 지수(Shannon entropy) 2.3 (검객 1.6 / 전사 1.9 대비) → 영매 직업 유저가 가이드 사이트에서 가장 활발히 빌드 공유.
- **PvP 유저는 효율 최적화**: 결투장 빌드 TOP10 누적 91.1% → 효율 우선. 가이드 사이트의 PvP 시뮬레이터(V2)에서 추천 시 효율 + 다양성 균형 권장.

## 5. 권고사항 (4399/Joy Games 적용 가능 액션 10건)

1. **직업 균형 패치**: 검객 메타 50% 임계 돌파 직전. 검객 코어 스킬 -3% 또는 영매 코어 스킬 +5% 검토.
2. **결투장 보상 다양성 인센티브**: 같은 진령 3종 빌드로 결투장 진입 시 보상 -10%, 새 빌드 시도 시 +15% 보너스.
3. **신규 진령 출시 패키지 가격 인하**: 신규 진령 가챠 패키지 ₩16,000 → ₩9,900 검토. 출시 후 48h 채용률 +5%p 목표.
4. **0티어 진령 너프 검토**: 홍길동·서해용왕 채용률 70%+ 12주 지속 → 다음 분기 너프 또는 1티어 진령 상향.
5. **영매 직업 콘텐츠 강화**: 영매 빌드 다양성 활발 → 영매 전용 시즌 패키지 또는 광역 던전 추가.
6. **결투장 빌드 다양성 KPI 도입**: 결투장 메타 빌드 TOP1 점유율 30% 이하 유지 목표.
7. **신규 SSR 진령의 검객 시너지 우선 설계**: 검객 빌드 다양성 부족 (Shannon 1.6) → 검객 특화 신규 진령 출시.
8. **2티어 진령 상향**: 격투귀·산신 채용률 12% 이하 → 효과 +15% 또는 패시브 추가.
9. **시즌 패키지 효과 정량 측정**: 시즌 패키지 출시 주(W5/W9)에 ±5%p 변동 → 시즌 효과 알람 자동화.
10. **신규 유저 첫 7일 빌드 추천 시스템**: 신규 유저 최초 빌드 결정에 0티어 정석 추천 → 결투장 진입 시 자동 변형 추천.

| 가입 추이 (참고) | 회원 코호트 | `users` | `created_at` 주별 group |

⚠️ **매핑 이슈**:
- **R1-C5**: `description`은 자유 텍스트라 정확 검색 어려움. **MVP 스키마에 `builds.tags: string[]` 필드 추가 권장** (V1 빌드 작성 폼에서 카테고리 multi-select).
- **신규 진령 출시일**: 운영자가 별도 관리하는 `events_calendar.md` 외부 파일 필요 (게임사 패치 노트 수기 기록). 또는 게임사 API 제공 시 자동 동기화.
