### 1.2 P3.A에서 자동 추가 (1건)

```
AUTH_SECRET           # openssl rand -base64 32 (이미 자동 생성됨)
```

### 1.3 운영자가 추가해야 할 항목 (5건)

```bash
# Google OAuth (https://console.cloud.google.com/apis/credentials)
tene set GOOGLE_CLIENT_ID --stdin     # 입력 prompt에서 값 입력
tene set GOOGLE_CLIENT_SECRET --stdin

# Kakao OAuth (https://developers.kakao.com/console/app)
tene set KAKAO_CLIENT_ID --stdin      # REST API 키
tene set KAKAO_CLIENT_SECRET --stdin  # client secret (선택, 강력 권장)

# Firebase Admin SDK (Firebase Console > 프로젝트 설정 > 서비스 계정 > 새 비공개 키 생성)
# 다운로드 받은 JSON 파일 내용을 base64로 인코딩 후 등록:
base64 -i serviceAccount.json | tene set FIREBASE_SERVICE_ACCOUNT_JSON --stdin
```

> **보안 주의** (CLAUDE.md tene policy):
>  - `tene get <KEY>` 금지 — 값이 stdout에 노출됨
>  - `tene set <KEY> <VALUE>` 금지 — 값이 argv에 노출됨
>  - `tene export` 금지 — 모든 plaintext 노출
>  - 항상 `--stdin` 사용

## 2. Google Cloud OAuth 등록

1. https://console.cloud.google.com/apis/credentials 접속
2. **OAuth 2.0 클라이언트 ID 생성** → 웹 애플리케이션
3. 승인된 JavaScript 원본:
   - `http://localhost:3000`
   - `https://god-kkabi-guide.vercel.app`
   - (커스텀 도메인 — P3.D 단계)
4. 승인된 리디렉션 URI:
   - `http://localhost:3000/api/auth/callback/google`
   - `https://god-kkabi-guide.vercel.app/api/auth/callback/google`
5. 발급된 `Client ID` / `Client Secret`을 tene에 등록 (§1.3)

## 3. Kakao Developers 등록

1. https://developers.kakao.com/console/app 접속
2. **새 애플리케이션 추가** → 앱 이름 "갓깨비 키우기 가이드"
3. **플랫폼 → Web → 사이트 도메인 등록**:
   - `http://localhost:3000`
   - `https://god-kkabi-guide.vercel.app`
4. **카카오 로그인 → 활성화 ON**
5. **Redirect URI 등록**:
   - `http://localhost:3000/api/auth/callback/kakao`
   - `https://god-kkabi-guide.vercel.app/api/auth/callback/kakao`
6. **동의 항목 설정**:
   - 닉네임 (필수)
   - 프로필 사진 (선택)
   - 카카오계정 이메일 (선택)
7. **Client Secret 발급** (보안 → 활성화)
8. **REST API 키 + Client Secret을 tene에 등록** (§1.3)

## 4. Firebase Console 설정

### 4.1 Authentication 활성화
1. https://console.firebase.google.com/project/god-kkabi-guide/authentication 접속
2. **Sign-in method**에서 **Google** + **Custom (匿名)** 활성화
   - Kakao는 Custom Token bridge로 처리 — Custom signing 활성화 필요

### 4.2 Firestore Database 활성화 + Composite Index
1. **Firestore Database** → **데이터베이스 만들기** → 위치: `asia-northeast3` (서울)
2. **모드**: 프로덕션 (Security Rules은 §4.4 적용)
3. **Composite Index** 생성 — `docs/sprint/03-sprint-mvp-v2/phase-2-design/firestore-schema.md`의 인덱스 JSON 10건을 Firebase Console > Firestore > 색인 탭에서 등록

### 4.3 Realtime Database 활성화 (P3.D 단계)
- Spark Plan에서 RTDB 활성화 — 100 동시 연결 한도 모니터링

### 4.4 Security Rules 배포
```bash
# firebase.json + firestore.rules + database.rules.json 생성 후
firebase deploy --only firestore:rules
firebase deploy --only database
```

### 4.5 Firebase Service Account JSON
1. **프로젝트 설정 → 서비스 계정 → 새 비공개 키 생성**
2. 다운로드 받은 `serviceAccountKey.json`을 안전한 곳에 보관 (절대 git commit 금지)
