## 4. 운영자 role=admin custom claim 부여

NextAuth는 기본적으로 role=user를 부여합니다. 운영자(kay@agentkay.it)에게는 별도 admin claim이 필요합니다.

### 4.1 1회 부여 스크립트 (서버에서 직접 실행)
```bash
# scripts/grant-admin.ts 신규 작성 후 실행
# 또는 Firebase Console > Authentication > 사용자 → custom claims 직접 입력
```

권장 방식: **scripts/grant-admin.ts** 작성

```ts
// scripts/grant-admin.ts (P3.D.5에서 작성하지 않음 — 운영자 1회 사용)
import 'dotenv/config';
import { getAuth } from 'firebase-admin/auth';
import { initializeApp, cert } from 'firebase-admin/app';

const sa = JSON.parse(Buffer.from(process.env.FIREBASE_SERVICE_ACCOUNT_JSON!, 'base64').toString('utf8'));
initializeApp({ credential: cert(sa) });

const targetEmail = 'kay@agentkay.it';
const user = await getAuth().getUserByEmail(targetEmail);
await getAuth().setCustomUserClaims(user.uid, { role: 'admin' });
console.log(`✅ ${targetEmail} → role=admin`);
```

실행: `tene run -- npx tsx scripts/grant-admin.ts`

### 4.2 운영자 본인 firestore users 문서에도 role=admin 갱신
NextAuth Adapter는 자동으로 role=user를 저장하므로 등록 후 admin 콘솔 (또는 Firestore 콘솔)에서 `users/{uid}.role` = `'admin'`으로 수동 변경.
