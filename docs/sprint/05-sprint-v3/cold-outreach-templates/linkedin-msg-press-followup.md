# Cold Outreach 변형 C — 우회 (보도자료 후 follow-up)

> 먼저 한국/해외 게임 매체에 보도자료 발송 → 보도 링크가 게임사에게 도달한 후 follow-up.
> 강점: 권위 확보. 약점: 보도자료 작성 비용 + 매체 채택 불확실.

## Step 1: 보도자료 (Press Release)

### Subject
```

```

### 발송 대상 (한국 5건)

- 인벤 (게임 산업 뉴스)
- 디스이즈게임 (산업 분석)
- 게임포커스
- ZDNet Korea (게임 섹션)
- 한국경제 게임 섹션

### 발송 대상 (해외 5건)

- Pocket Gamer (UK, 모바일 게임)
- App2Top (RU, 글로벌 모바일)
- GamesIndustry.biz (UK)
- Sensor Tower 블로그 (산업 분석)
- AppMagic / data.ai 뉴스레터

```
1. 1인 운영 팬 가이드가 22개월 만에 누적 10K+ 빌드 + 100+ NLP 토픽 자산화
2. 데이터는 분기 메타 인사이트로 게임사 라이선스 가능 (₩30M-100M/년 가격대)
```
