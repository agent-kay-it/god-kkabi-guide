## 1. 시드 채널 전략 개요

비공식 팬 가이드 사이트는 브랜드 인지도 0에서 시작하므로 유기적(organic) SEO가 효과를 발휘하기 전 3-8주간의 공백 기간 동안 커뮤니티 기반 수동 시드 트래픽이 반드시 필요하다. 시드 트래픽이 없으면 GSC 인덱싱 신호가 0이 되어 SERP 상위 진입 자체가 불가능해진다.

P1 검투호(검객 직업 + 메타 추종 + 디시/카페 활용 25-40세 남성)가 이미 모여 있는 커뮤니티 채널 5개를 우선순위대로 침투한다. 목표는 사이트 홍보가 아닌 **정보 제공자로서의 신뢰 확립**이다.

## 2. 시드 채널 5개 우선순위

### 2.1 [P0] 디시인사이드 갓깨비 키우기 마이너 갤러리

- **URL**: https://gall.dcinside.com/mgallery/board/lists/?id=up999
- **활성도**: 일 30-80 글, 시간대별 현황 타임라인 게시 활발 (2025년 게임 출시 이후 가장 활발한 한국어 커뮤니티)
- **타겟 독자**: P1 검투호 밀집 (전사/검객/영매 빌드 토론, 쿠폰 최초 발견, 메타 변화 실시간 감지)
- **침투 전략**: 마이너 갤러리는 외부 링크에 관대하지 않으므로 **정보 글이 본론, 링크는 마지막 1줄 주석** 원칙을 고수한다.

**운영 규칙**:
1. 닉네임은 매 세션 동일하게 유지 (IP 기반 닉네임 고정이므로 고정 닉 자연 형성)
2. 링크 직노출 금지. `갓깨비 키우기 쿠폰 - 갓깨비가이드 닷컴 [검색]` 형식
3. 가입 후 3회 이상 댓글/정보 글 기여 후 첫 링크 게시
4. 글 형식: **정보 내용 본론 → 마지막 줄에 "더 자세한 내용은 god-kkabi.guide 참조"**

**유효 게시 유형**:
- 쿠폰 신규 발견 즉시 공유 (복붙 가능, D-day 알림 포함)
- 메타 빌드 변경 정보 (패치 직후 24h 이내)
- 진령 티어 논쟁 중재 글 (객관 수치 기반)

**피해야 할 유형**:
- 사이트 직접 홍보 문구 ("제 사이트 방문해주세요")
- 반복 링크 게시 (동일 글에 2개 이상)
- 가입 후 첫 글부터 링크 포함

### 2.2 [P1] 네이버 갓깨비 카페 5곳

네이버 검색 결과에서 "갓깨비 키우기 카페"로 찾을 수 있는 활성 카페. 운영자가 직접 검색 후 가입 신청해야 하며, 이하 지침을 따른다.

**카페 발굴 방법**:
```
네이버 검색: 갓깨비 키우기 카페
네이버 카페 탭 → 가입자 500+ + 주간 글 5+ 기준으로 선별
```

**침투 전략**:
1. **가입 대기 기간 7일 준수**: 네이버 카페는 가입 직후 링크 게시 시 스팸 탐지 알고리즘에 걸릴 수 있음. 최소 7일간 댓글 활동 후 첫 링크 게시.
2. **레벨업 우선**: 대부분의 갓깨비 카페는 레벨업 조건(글 5개 이상 등)이 있으므로 정보성 댓글로 레벨 먼저 확보.
3. **카페 마다 다른 톤**: 정보 공유형 카페는 진령 티어 분석 글, 초보 질문 카페는 직업 진단 링크.

**게시 템플릿**:
```
제목: 갓깨비 키우기 검객 메타 빌드 정리해봤습니다 (2026년 5월 기준)

본문:
[검객 메타 빌드 핵심 요약 내용 500자+]
진령 조합: 홍길동 + 서해용왕 + 음영귀 기준으로 결투장 승률이 가장 높습니다.
코어 스킬 우선순위: [...]

더 자세한 스킬 제련 조합이 궁금하신 분은
→ god-kkabi.guide 에 정리해뒀습니다.
```

### 2.3 [P1] 카카오톡 갓깨비 키우기 단톡방

- **대상**: 검투호 P1이 모여 있는 비공개 단톡방. 디시 마이너 갤러리에서 "단톡방 초대" 글을 통해 접근.
- **진입 방법**: 디시 갤러리에서 오픈 카톡방 URL이 주기적으로 공유됨 → 가입 후 활동.

**침투 전략**:
1. 단톡방은 완전히 다른 규칙이 적용됨. **직접 링크 금지** (즉각 추방 가능).
2. 대신 **방장/핵심 멤버와 신뢰 형성 후 자연스러운 추천** 유도.
3. 쿠폰 공유 채널로 먼저 기여 (쿠폰 코드 복붙만으로도 가치 인정).
4. "이거 어디서 찾으셨어요?" 질문 유도 → "제가 정리해둔 사이트가 있는데..." 자연 소개.

**쿠폰 공유 시나리오**:
```
[갓깨비 쿠폰 알림]
코드: GOKKAEBI2026 (진령 소환권 10장)
만료: 2026-05-31
god-kkabi.guide/coupon 에서 D-day 확인 가능합니다
```

### 2.4 [P2] YouTube 게임 매체 댓글

- **주요 대상 채널**: BlueStacks 한국 채널, 게임어바웃(GameAbout), 게임조선 YouTube
- **영상 유형**: 갓깨비 키우기 리뷰/공략 영상 댓글 섹션

**침투 전략**:
1. 영상 댓글에 **정보 보완 댓글** 형식으로 기여. "영상에서 언급 안 된 ○○ 정보 추가합니다."
2. 좋아요 5+ 받은 댓글이 상단 노출되므로 콘텐츠 퀄리티 최우선.
3. 댓글 예시:
```
영상 잘 봤습니다. 추가로 검객 결투장 빌드는 홍길동 + 서해용왕 + 음영귀 조합이
현재(2026년 5월) 결투장 점유율이 가장 높아요. 더 자세한 스킬 제련 조합은
god-kkabi.guide/builds/meta-swordsman 에 정리해뒀습니다.
```
4. 동일 채널 동일 영상에 1개 댓글만 (반복 금지, YouTube 스팸 처리 가능).

### 2.5 [P3] 루리웹 / 게임메카 / 보배드림 게임 게시판 (보조 채널)

- **위상**: 트래픽은 있으나 갓깨비 키우기 유저 밀집도 낮음 → 보조 채널 위치
- **활용 방법**: 게임 전반 공략 글 게시 시 링크 자연 삽입
- **우선순위**: 디시/카페/카톡 시드 안착 후 M2부터 진입

## 3. 운영자 운영 규칙 (자가홍보 신고 회피)

### 3.1 정체 노출 방지 원칙

1인 운영자 신분을 노출하면 "자기 사이트 홍보"로 낙인찍혀 신고 및 밴 위험이 있다. 다음 원칙을 반드시 준수한다.

| 규칙 | 내용 |
|------|------|
| **닉네임 일관성** | 디시·카페·YouTube 모두 동일 닉네임 사용 금지 (채널별 별도 닉네임) |
| **운영자 정체 미노출** | "제 사이트", "제가 만든" 표현 금지. 외부 자료인 것처럼 소개 |
| **가치 먼저** | 링크 없는 정보 기여 글을 먼저 올리고 신뢰 형성 후 링크 게시 |
| **반복 게시 금지** | 같은 링크를 동일 채널에 하루 2번 이상 게시 금지 |
| **대화형 참여** | 링크 게시 글에 다른 사람 댓글에 반드시 답변 (활성 유저로 인식) |

### 3.2 디시 마이너 갤러리 특별 규칙

디시인사이드는 IP 기반 고정닉 시스템이므로 IP가 달라지면 닉네임도 달라진다. 일관된 IP 환경(고정 IP 또는 모바일 동일 네트워크)에서 활동한다.

```
디시 갤러리 광고 신고 조건:
- 동일 글에서 동일 URL 3번 이상 → 자동 신고 대상
- 첫 글에서 링크 게시 → 갤러리 운영진 수동 삭제 가능
- "광고 글"이라는 제목이나 인식 → 신고 급증
```

### 3.3 링크 표기 방식 (단계별)

| 단계 | 표기 방식 | 비고 |
|------|--------|------|
| 초기 (1-2주) | 링크 없음. "god-kkabi.guide 검색" | URL 직노출 없이 검색 유도 |
| 신뢰 형성 후 | `god-kkabi.guide/coupon` (프로토콜 없이) | 클릭 불가한 텍스트 URL |
| 안착 후 | `[갓깨비 가이드](https://god-kkabi.guide/coupon)` (카페 한정) | 마크다운 지원 채널에서만 |

## 4. 시드 콘텐츠 우선순위

시드 침투 시 어떤 콘텐츠 페이지를 먼저 공유하는지가 전환율을 결정한다. 다음 순서로 우선 활용한다.

### 4.1 1순위: 쿠폰 자동 체커 (`/coupon`)

**이유**: 즉각적인 가치 제공. 방문자가 쿠폰 하나를 복사하는 순간 사이트 가치를 체감한다. 커뮤니티에서 "쿠폰 정리해둔 사이트"로 입소문 나기 가장 쉬운 페이지.

**시드 메시지 예시**:
```
갓깨비 키우기 쿠폰 코드 정리:

GOKKAEBI2026 - 진령 소환권 10장 (만료 05/31)
KKABI0505 - 다이아 500 (만료 미정)

god-kkabi.guide/coupon 에 D-day 자동 표시해뒀습니다
```

### 4.2 2순위: 검객 메타 빌드 (`/builds/meta-swordsman`)

**이유**: P1 검투호의 핵심 수요. "결투장에서 지고 있는데 메타 빌드가 뭔지 모르겠다"는 Pain Point를 직접 해결한다. Beachhead 핵심 페이지.

**시드 메시지 예시**:
```
검객 결투장 메타 빌드 최신 정리 (2026.05)

핵심 조합: 홍길동 + 서해용왕 + 음영귀
코어 스킬: [...]
제련 우선순위: [...]

스킬 상세 + 제련 조합은 god-kkabi.guide/builds/meta-swordsman 참조
```

### 4.3 3순위: 진령 11종 티어 (`/jinryeong`)

**이유**: 999뽑기 결정 전 조회 수요가 매우 높음. 진령 뽑기 이벤트나 패치 직후 검색 트래픽 급증.

**시드 메시지 예시**:
```
진령 티어 현황 정리 (2026.05 기준)

0티어: 홍길동 / 서해용왕 / 음영귀
1티어: 명왕 / 치우 / 격투귀
2티어: 구미요호 / 항아 / 태양여신

상세 스킬 + 직업별 추천은 god-kkabi.guide/jinryeong 참조
```

## 5. UTM 파라미터 추적 전략

GA4 referrer만으로는 커뮤니티별 정확한 출처를 구분하기 어렵다. UTM 파라미터를 채널별로 구분하여 정확한 시드 효과를 측정한다.

### 5.1 UTM 파라미터 매핑

| 채널 | UTM 파라미터 | 예시 URL |
|------|----------|---------|
| 디시 마이너 갤러리 | `?utm_source=dcgall&utm_medium=community&utm_campaign=mvp-seed` | `god-kkabi.guide/coupon?utm_source=dcgall&utm_medium=community&utm_campaign=mvp-seed` |
| 네이버 카페 | `?utm_source=naver_cafe&utm_medium=community&utm_campaign=mvp-seed` | `god-kkabi.guide/coupon?utm_source=naver_cafe&utm_medium=community&utm_campaign=mvp-seed` |
| 카카오 단톡방 | `?utm_source=kakao_talk&utm_medium=chat&utm_campaign=mvp-seed` | `god-kkabi.guide/coupon?utm_source=kakao_talk&utm_medium=chat&utm_campaign=mvp-seed` |
| YouTube 댓글 | `?utm_source=youtube&utm_medium=comment&utm_campaign=mvp-seed` | `god-kkabi.guide/builds/meta-swordsman?utm_source=youtube&utm_medium=comment&utm_campaign=mvp-seed` |
| 루리웹/게임메카 | `?utm_source=ruliweb&utm_medium=community&utm_campaign=mvp-seed` | `god-kkabi.guide/?utm_source=ruliweb&utm_medium=community&utm_campaign=mvp-seed` |

> 주의: UTM URL은 텍스트로 공유 시 길어 보일 수 있으므로 카카오 단톡방에서는 bit.ly/tinyurl로 단축 후 UTM 보존.

### 5.2 GA4 커스텀 리포트 (Firestore events 컬렉션 연계)

`events` 컬렉션의 `referrer_source` 필드와 GA4 UTM 데이터를 교차 분석하여 채널별 전환율 측정:

```typescript
// design.md §5.3 events 컬렉션 referrer_source 매핑
referrer_source: 'organic'     // 검색
              | 'dc'           // 디시 마이너 갤러리
              | 'naver_cafe'   // 네이버 카페
              | 'kakao_talk'   // 카카오톡 단톡방
              | 'youtube'      // YouTube 댓글
              | 'direct'       // 직접 입력
```

## 6. 법적·윤리적 가드레일

### 6.1 운영자 신원 보호

| 상황 | 대응 |
|------|------|
| "이 사이트 운영자세요?" 질문 | "아니요, 저도 플레이어인데 좋은 사이트 발견해서 공유하는 것"이라고 부인. 단, 운영자임이 명백한 상황에서 적극적 부인은 윤리적 문제 → 침묵 또는 화제 전환 |
| 운영자 정체 드러남 | 정직하게 인정. "팬 가이드 만들었습니다. 도움이 됐으면 좋겠어요." — 이 경우 자연스럽게 운영자 투명성이 신뢰 자산이 됨 |
| 스팸 신고 받음 | 해당 글 자진 삭제 후 해당 채널에서 2주 관찰 후 재진입 |

### 6.2 자가홍보 신고 회피

커뮤니티마다 자가홍보에 대한 허용도가 다르다:

| 커뮤니티 | 외부 링크 허용도 | 대응 전략 |
|---------|------------|---------|
| 디시 마이너 갤러리 | 낮음 (신고 활발) | 링크 자제, 검색어 유도 |
| 네이버 카페 | 중간 (운영진에 따라 다름) | 7일 후 게시, 운영진 규칙 사전 확인 |
| 카카오 단톡방 | 낮음 (방장 재량) | 직접 링크 금지, 인적 네트워크로 소개 |
| YouTube 댓글 | 높음 (Google 알고리즘) | 댓글에 링크 자유 가능 |
| 루리웹 | 중간 | 공략 글 형태로 게시 |

### 6.3 비공식 사이트 명시

시드 메시지에는 반드시 비공식 팬 가이드임을 밝힌다. 공식 정보처럼 오인될 수 있는 표현은 사용하지 않는다.

```
❌ 금지: "공식 갓깨비 키우기 가이드"
❌ 금지: "갓깨비 공식 사이트"
✅ 허용: "비공식 팬 가이드"
✅ 허용: "팬이 정리한 공략 사이트"
✅ 허용: "갓깨비 가이드 (비공식)"
```
